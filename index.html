စာတန်းပါ ဗီဒီယို ထုတ်ရန်

စာတန်းကို ဗီဒီယိုထဲ တိုက်ရိုက် မြှုပ်ပြီး MP4 ဖိုင် ထုတ်ပေးမည်။ ဒီ browser က MP4 မထုတ်နိုင်ရင်သာ WebM နဲ့ ထုတ်ပေးမည်ဖြစ်ပြီး အဲဒါဆို စတင်ခင် ကြိုပြောပြပါမည်။

Render က ဗီဒီယို အရှည်အတိုင်း အချိန်ယူပြီး ဗီဒီယိုကို တစ်ခါ ပြန်ဖွင့်ရင်း မှတ်တမ်းတင်တာ ဖြစ်လို့ ပြီးတဲ့အထိ ဒီ tab ကို ဖွင့်ထားပါ။ အသံလည်း ပါမည် (browser က ထောက်ပံ့ရင်)။ ထုတ်လာတဲ့ ဖိုင်က ပုံမှန်အားဖြင့် MP4 ဖော်မတ် ဖြစ်ပါတယ်။ WebM ဖိုင် ထုတ်ပေးရတဲ့ အခါမျိုးမှာသာ ဖုန်းရဲ့ မူရင်း player မှာ အမည်း ပေါ်နေရင် Chrome သို့မဟုတ် VLC app နဲ့ ဖွင့်ကြည့်ပါ။

Short ဗီဒီယို ဖန်တီးရန် (9:16 / 16:9)

နောက်ခံ (ပုံ/ဗီဒီယို အရေအတွက် အကန့်အသတ် မရှိ၊ အစဉ်လိုက် ဆက်ဖွင့်မည်) + အသံဖိုင် + စာတန်း ပေါင်းပြီး 1080×1920 Short ဗီဒီယို ထုတ်ပေးမည်။ ပုံဆိုရင် ဖြည်းဖြည်းချင်း zoom ဝင်သွားမည် (Ken Burns ပုံစံ)၊ ဗီဒီယို ဆိုရင် လှုပ်ရှားနေတဲ့ နောက်ခံ အဖြစ် ဖွင့်ပေးမည်။ စာတန်း ပုံစံနဲ့ နေရာက အပေါ်က “စာတန်း ပုံစံ” setting အတိုင်း သုံးပါမည် — preview ပေါ်မှာ ဆွဲရွှေ့ထားတဲ့ နေရာ အတိုင်း ပါမည်။

Preview နဲ့ Export အရွယ်အစား နှစ်ခုလုံး ရွေးထားတဲ့ အချိုးအစား အတိုင်း ပြောင်းပါမည်။

9:16 preview ပေါ်မှာ YouTube Shorts / Reels ရဲ့ ဘေးခလုတ်တွေနဲ့ အောက် caption နေရာတွေ ဖုံးတတ်တဲ့ နေရာတွေကို အနီအရိပ် နဲ့ ပြပေးပါမည် — စာတန်းကို အဲဒီ နေရာတွေ မထားမိအောင် ကြည့်ပြီး ညှိနိုင်ပါတယ်။ Export ထဲ မပါပါ။

နောက်ခံ မရှိသေးပါ — အောက်က ခလုတ်တွေနဲ့ ပုံ သို့မဟုတ် ဗီဒီယို ထည့်ပါ။

ပုံ/ဗီဒီယို ဘယ်အချိုးအစား ဖြစ်ဖြစ် ရပါတယ် — ရွေးထားတဲ့ frame (1080×1920) နဲ့ မကိုက်ရင် အလယ်က ဖြတ်ပြီး ဖြည့်ပေးပါမည်။ ဗီဒီယိုထဲက အသံ မပါပါ — အသံဖိုင်ရဲ့ အသံကိုပဲ သုံးပါမည်။ ပုံ တစ်ပုံချင်းစီ ပြသချိန်ကို စက္ကန့်နဲ့ ချိန်နိုင်ပြီး၊ ဗီဒီယိုကတော့ သူ့ မူရင်း အရှည်အတိုင်း ဖွင့်ပါမည်။

ဖွင့် — နောက်ခံ အစဉ် တစ်ခုလုံး အသံ မပြီးမချင်း ပြန်လည် ဖွင့်နေမည်။ ပိတ် — တစ်ခါပဲ ဖွင့်ပြီး အစဉ် ပြီးသွားရင် နောက်ဆုံး item ရဲ့ နောက်ဆုံး frame ကို ဆက်ပြထားမည်။
